# Apple Health → Intervals.icu для утреннего отчёта

Утренний отчёт тренера читает данные только из Intervals.icu (wellness).
Apple Health доступен лишь на iPhone, поэтому телефон должен каждое утро
отправлять метрики в Intervals.icu. Отчёт сам подхватит всё, что пришло;
пустые поля он молча пропускает.

## Какие поля читает отчёт

| Apple Health                         | Поле wellness в Intervals.icu | Как используется в отчёте |
|--------------------------------------|-------------------------------|---------------------------|
| Вариабельность пульса (SDNN, мс)      | `hrvSDNN`                     | готовность (если `hrv` пуст), пороги 85% / 75% от нормы |
| Пульс в покое                         | `restingHR`                   | готовность, +4 к норме = сигнал |
| Сон (сумма фаз, без «В кровати»)      | `sleepSecs`                   | готовность, 3 ч или 10+ ч = ненадёжно |
| Оценка сна (watchOS 26)               | `sleepScore`                  | готовность, <60 две ночи = сигнал |
| Средний пульс во сне                  | `avgSleepingHR`               | +4 к норме = сигнал |
| Частота дыхания                       | `respiration`                 | +1 вдох/мин к норме = сигнал |
| Насыщение крови кислородом            | `spO2`                        | <94% две ночи = пометка, <90% = к врачу |
| Кардиофитнес (VO2 max)                | `vo2max`                      | тренд за 4 недели в разделе «Неделя» |
| Вес                                   | `weight`                      | тренд за 7 дней |
| Шаги (за вчера)                       | `steps`                       | 20 000+ = доп. нагрузка |
| Активные калории (опционально)        | `kcalConsumed`                | справочно |
| Температура запястья во сне (опц.)    | своё поле, напр. `WristTemp`  | +0,5 °C к норме = сигнал |

Для температуры запястья создайте своё поле wellness в Intervals.icu
(Settings → Wellness → Custom fields), код поля, например, `WristTemp`.

## Вариант 1: готовое приложение

Если HRV, пульс покоя и сон уже появляются в Intervals.icu сами, значит
синхронизация с Apple Health настроена. Проверьте в её настройках, что
включены также пульс во сне, дыхание, SpO2, VO2 max и вес.

## Вариант 2: Быстрая команда (Shortcuts) на iPhone

1. Shortcuts → Автоматизация → «Время суток», 06:15, ежедневно,
   «Запускать сразу» (без подтверждения).
2. Для каждой метрики: «Найти образцы здоровья», тип = метрика,
   «Дата начала» = за последние 12 часов (шаги и калории — вчера),
   сортировка по дате, лимит 1 (для шагов и сна — «Вычислить статистику»: сумма).
   SpO2 Apple отдаёт долей (0,97): умножьте на 100.
3. Действие «Дата» → «Форматировать дату» в `yyyy-MM-dd` → переменная `D`.
4. «Получить содержимое URL»:
   - URL: `https://intervals.icu/api/v1/athlete/i663714/wellness/<D>`
   - Метод: `PUT`
   - Заголовки: `Authorization: Basic <base64 от "API_KEY:ВАШ_КЛЮЧ">`,
     `Content-Type: application/json`
   - Тело (JSON), только поля, которые нашлись:

```json
{
  "id": "<D>",
  "hrvSDNN": 58,
  "restingHR": 47,
  "avgSleepingHR": 52,
  "respiration": 14.2,
  "spO2": 97,
  "sleepSecs": 25200,
  "vo2max": 41.3,
  "weight": 74.5,
  "steps": 9700
}
```

Ключ API храните только в Быстрой команде, не в этом репозитории.
Base64 можно получить действием «Кодировать Base64» прямо в команде.

Команда должна отработать до 06:39 (время запуска отчёта по Иерусалиму).

## Графики

Утренний отчёт каждый день обновляет страницу с графиками «Форма Ивана»
(https://claude.ai/artifact/XAL6VtVNX42cqQ2SAUsY8S): CTL/ATL/TSB, объём по
неделям, HRV, пульс покоя и во сне, сон, дыхание, SpO2, температура запястья,
VO2max, вес и шаги за 28 дней. Шаблон страницы лежит в `dashboard/template.html`,
данные вставляются в блок `<script id="health-data">` скриптом `dashboard/build.py`.
